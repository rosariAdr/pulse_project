# Finishing V0 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The multi-agent runner for this plan is `.claude/workflows/pulse-v0-finish.js` (one wave per launch).

**Goal:** Take the entrance-test loop from "works on the in-memory demo" to "ready for a real class": CI green, scope written down, guardrails enforced by CI, the reset-password screen, the database coverage gaps closed, the Supabase implementation proven against a real Postgres, and the pilot-day kit.

**Architecture:** React + Vite SPA on Vercel; Supabase (EU) through one repository interface (`src/data/repo.ts`) with two implementations — Supabase and an in-memory double. Rules live in the database (RLS + triggers) and are proven by pgTAP. Work is split into tasks that each produce one PR into `dev`.

**Tech Stack:** React 19, TypeScript 6, Vite 8, Tailwind v4, react-router 8, @supabase/supabase-js 2, Vitest 3 + Testing Library, Playwright, Supabase CLI 2 + pgTAP, GitHub Actions, gh CLI.

**Spec:** `docs/superpowers/specs/2026-10-18-v0-finish-design.md`

## Global Constraints

- Branches: cut `feat/<slug>` (or `fix/`, `docs/`, `chore/`) from `origin/dev`; open the PR into `dev`. Never push or merge to `main`. Never force-push. Never delete a branch. Never change GitHub, Vercel or Supabase settings.
- Secrets: never read, print, use or commit the `service_role` key or any `sb_secret_` key. Check `.env.local` only with `grep -c` (counts), never `cat`.
- Database: every schema/RLS change is a **new** file in `supabase/migrations/` plus a pgTAP test in `supabase/tests/` in the same PR. Never edit `20261003000000_v10_schema.sql` or `20261004120000_v0_hardening.sql`. Run SQL only against the local stack (`npm run db:reset`, `npm run db:test`). Never `supabase db push`, never `supabase link`.
- Tests: fix code, not tests. A test may change only if it is itself wrong, and the PR description says why. No `.skip`, `.only`, `test.fixme`, lowered `plan(n)`, or deleted assertions.
- Data: demo data only, `.example` addresses. No real names or emails in the repository.
- Interface strings live in `src/i18n/en.ts` (English). Anything that moves uses the `pl-*` classes. Student screens are checked at phone width.
- A refusal is shown to the person, never swallowed. No score, ranking or aggregate is shown to a student.
- Commit messages end with: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. PR descriptions end with: `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- Before opening a PR, `npm run verify` passes (it exists from Task 3; before that: `npm run lint && npm run typecheck && npm test && npm run build`).

- [ ] **Step 3: Implement** — `scripts/lib/secrets.mjs`

```js
/**
 * Finds what must never be committed. Pure: a path and its text in, findings out.
 * A finding names the file, the line and the kind of secret — never the value.
 */
const JWT = /eyJ[A-Za-z0-9_-]{10,}\.eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}/g
const SECRET_KEY = /sb_secret_[A-Za-z0-9_-]{8,}/
const DB_URL = /postgres(?:ql)?:\/\/[^:\s/@]+:([^@\s]+)@([^/\s:]+)/g
const LOCAL_HOSTS = new Set(['127.0.0.1', 'localhost', '0.0.0.0', 'db', 'host.docker.internal'])

function jwtRole(token) {
  try {
    return JSON.parse(Buffer.from(token.split('.')[1], 'base64url').toString('utf8')).role ?? null
  } catch {
    return null
  }
}

const isPlaceholder = (password) => password.startsWith('[') || password.startsWith('$') || password.startsWith('<')

export function findSecrets(path, text) {
  const findings = []
  const base = path.split('/').pop() ?? path

  if (base === '.env' || (base.startsWith('.env.') && base !== '.env.example')) {
    findings.push({ path, line: 0, reason: 'an env file is tracked' })
  }

  text.split('\n').forEach((content, index) => {
    const line = index + 1
    for (const match of content.matchAll(JWT)) {
      if (jwtRole(match[0]) === 'service_role') {
        findings.push({ path, line, reason: 'a Supabase service_role key' })
      }
    }
    if (SECRET_KEY.test(content)) findings.push({ path, line, reason: 'a Supabase secret key' })
    for (const match of content.matchAll(DB_URL)) {
      const [, password, host] = match
      if (!LOCAL_HOSTS.has(host) && !isPlaceholder(password)) {
        findings.push({ path, line, reason: 'a database password' })
      }
    }
  })

  return findings
}
```

- [ ] **Step 5: The command** — `scripts/check-secrets.mjs`

```js
#!/usr/bin/env node
/**
 * Fails when a tracked file holds a secret. Runs in CI on every PR and in
 * `npm run verify`. Prints where, never what.
 */
import { execFileSync } from 'node:child_process'
import { readFileSync, statSync } from 'node:fs'
import { findSecrets } from './lib/secrets.mjs'

const files = execFileSync('git', ['ls-files', '-z'], { encoding: 'utf8' }).split('\0').filter(Boolean)
const findings = []

for (const path of files) {
  try {
    if (statSync(path).size > 1_000_000) continue
  } catch {
    continue
  }
  findings.push(...findSecrets(path, readFileSync(path, 'utf8')))
}

if (findings.length > 0) {
  console.error('Secrets in tracked files. Remove them, rotate them in Supabase, then push again:')
  for (const f of findings) console.error(`  ${f.path}:${f.line}  ${f.reason}`)
  process.exit(1)
}
console.log(`No secrets in ${files.length} tracked files.`)
```

import { Link } from 'react-router'
import { useSession } from '../../app/session'
import { PulseError } from '../../data/types'
import { en, messageForError } from '../../i18n/en'
import { Button, Card, Ground, TextField } from '../../ui/pulse-ui-kit/react'

const MIN_PASSWORD = 8

/**
 * Where the reset link lands. The link signs the person in for one purpose —
 * choosing a new password — so this screen shows whatever the session is.
 * Mobile-first, like the rest of the door.
 */
export function ResetPasswordScreen() {
  const { repo } = useSession()
  const [password, setPassword] = useState('')
  const [error, setError] = useState<string | null>(null)
  const [done, setDone] = useState(false)
  const [busy, setBusy] = useState(false)

  async function onSubmit(event: FormEvent) {
    event.preventDefault()
    setError(null)
    if (password.length < MIN_PASSWORD) {
      setError(en.door.passwordTooShort(MIN_PASSWORD))
      return
    }
    setBusy(true)
    try {
      await repo.auth.updatePassword(password)
      setDone(true)
    } catch (e) {
      setError(e instanceof PulseError ? messageForError(e.code) : en.common.error)
    } finally {
      setBusy(false)
    }
  }

  return (
    <div className="pl-app">
      <Ground />
      <main className="mx-auto flex min-h-screen w-full max-w-md flex-col justify-center gap-6 px-4 py-10">
        <header className="text-center">
          <h1 className="font-serif text-h2">Pulse</h1>
        </header>
        <Card>
          {done ? (
            <>
              <p role="status">{en.door.passwordChanged}</p>
              <Link to="/" className="pl-btn pl-btn--primary pl-btn--lg pl-btn--block">
                {en.door.continue}
              </Link>
            </>
          ) : (
            <form onSubmit={onSubmit} noValidate>
              <h2 className="font-serif text-h3">{en.door.setNewPassword}</h2>
              <TextField
                id="new-password"
                label={en.door.newPassword}
                type="password"
                autoComplete="new-password"
                required
                hint={en.door.passwordTooShort(MIN_PASSWORD)}
                value={password}
                onChange={(e) => setPassword(e.target.value)}
              />
              {error && (
                <p className="pl-error" role="alert">
                  {error}
                </p>
              )}
              <Button type="submit" variant="primary" size="lg" block disabled={busy}>
                {busy ? '…' : en.door.setNewPassword}
              </Button>
            </form>
          )}
        </Card>
      </main>
    </div>
  )
}

import type { PulseRepo } from '../repo'
import { PulseError } from '../types'

/**
 * The repository's behaviour, written once and run against every
 * implementation. Scenarios run in order and share state, as a real database
 * does: each uses its own student so they do not interfere.
 *
 * If an implementation fails a scenario, fix the implementation. Change a
 * scenario only when the behaviour it states is wrong, and say why in the PR.
 */
export type ContractHarness = {
  repo: PulseRepo
  /** Signs this account in, creating it from its profile on first use. */
  actAs(email: string): Promise<void>
}

export const SEED = {
  stat: '00000000-0000-4000-8000-0000000000d1', // published test, class B1 · Groupe 2
  ddm: '00000000-0000-4000-8000-0000000000d2', // no test, class M2-03
  exerciseNotAQuestion: '00000000-0000-4000-8000-000000000101',
  lea: 'l.fontaine@idrac.example',
  yanis: 'y.cherif@idrac.example',
  lina: 'l.benali@abs.example',
  master: 'master@pulse.example',
}

async function codeOf(run: () => Promise<unknown>): Promise<string> {
  try {
    await run()
    return 'no-error'
  } catch (e) {
    return e instanceof PulseError ? e.code : `not a PulseError: ${String(e)}`
  }
}

export function describeRepoContract(name: string, setup: () => Promise<ContractHarness>) {
  describe.sequential(`PulseRepo contract — ${name}`, () => {
    let h: ContractHarness
    let leaAttempt = ''
    let q1 = ''
    let q2 = ''

    beforeAll(async () => {
      h = await setup()
    }, 60_000)

    it('refuses an email with no pre-created profile — no self-enrollment', async () => {
      await h.repo.auth.signOut()
      expect(await codeOf(() => h.repo.auth.claimProfile('stranger@nowhere.example', 'a-good-password'))).toBe(
        'NO_PROFILE',
      )
    })

    it('shows a student the modules of their own class only', async () => {
      await h.actAs(SEED.lea)
      expect((await h.repo.student.modules()).map((m) => m.title)).toEqual(['Statistiques commerciales'])
      expect(await h.repo.student.module(SEED.ddm)).toBeNull()
      expect(await h.repo.student.test(SEED.ddm)).toBeNull()
    })

    it('refuses to start the test of another class', async () => {
      expect(await codeOf(() => h.repo.student.startAttempt(SEED.ddm))).toBe('TEST_NOT_AVAILABLE')
    })

    it('saves answers as they are written and reads them back', async () => {
      const attempt = await h.repo.student.startAttempt(SEED.stat)
      leaAttempt = attempt.id
      const test = (await h.repo.student.test(SEED.stat))!
      ;[q1, q2] = test.questions.map((q) => q.id)

      await h.repo.student.saveAnswer(leaAttempt, q1, 'Une erreur de calcul')
      await h.repo.student.saveAnswer(leaAttempt, q1, 'Des étalements différents')

      const reread = (await h.repo.student.test(SEED.stat))!
      expect(reread.attempt?.id).toBe(leaAttempt)
      expect(reread.answers[q1]).toBe('Des étalements différents')
      expect(reread.answers[q2]).toBeUndefined()
    })

    it('allows one attempt per student per test', async () => {
      expect(await codeOf(() => h.repo.student.startAttempt(SEED.stat))).toBe('ATTEMPT_EXISTS')
    })

    it('refuses a question that belongs to another test', async () => {
      expect(await codeOf(() => h.repo.student.saveAnswer(leaAttempt, SEED.exerciseNotAQuestion, 'x'))).toBe(
        'NOT_AUTHORISED',
      )
    })

    it('refuses an answer longer than the database accepts', async () => {
      expect(await codeOf(() => h.repo.student.saveAnswer(leaAttempt, q2, 'x'.repeat(5001)))).toBe('ANSWER_TOO_LONG')
    })

    it('never lets a classmate read or write a student’s answers', async () => {
      await h.actAs(SEED.yanis)
      expect(await codeOf(() => h.repo.student.saveAnswer(leaAttempt, q1, 'overwritten'))).toBe('NOT_AUTHORISED')
      const own = (await h.repo.student.test(SEED.stat))!
      expect(own.attempt).toBeNull()
      expect(own.answers).toEqual({})
    })

    it('keeps the teacher’s views away from students', async () => {
      expect(await codeOf(() => h.repo.teacher.modules())).toBe('NOT_AUTHORISED')
      expect(await codeOf(() => h.repo.teacher.rawResults(SEED.stat))).toBe('NOT_AUTHORISED')
    })

    it('hands in once, then refuses changes out loud', async () => {
      await h.actAs(SEED.lea)
      const handed = await h.repo.student.handIn(leaAttempt)
      expect(handed.submittedAt).not.toBeNull()
      expect(await codeOf(() => h.repo.student.saveAnswer(leaAttempt, q2, 'after the bell'))).toBe('ATTEMPT_CLOSED')
      expect(await codeOf(() => h.repo.student.handIn(leaAttempt))).toBe('ATTEMPT_CLOSED')
      expect((await h.repo.student.module(SEED.stat))?.testStatus).toBe('handed-in')
    })

    it('gives the teacher every student of the class and exactly what they wrote', async () => {
      await h.actAs(SEED.master)
      const raw = await h.repo.teacher.rawResults(SEED.stat)

      expect(raw.students).toHaveLength(5)
      const lea = raw.answers.filter((a) => a.studentName === 'Léa Fontaine')
